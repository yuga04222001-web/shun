# シュン 配布リンク

瞬間英作文アプリ「シュン」の配布リンクページ。
端末を判定して App Store / Google Play のどちらかを主ボタンにする。

<https://yuga04222001-web.github.io/shun/>

- 自動遷移はしない（判定できた人がページを一度も見られなくなるため）
- 判定ロジックは `index.html` 内の `detect()`。`window.__detect` で単体テストできる
- 端末が分かったら自動でストアへ送る。`?stay` を付けると飛ばない（見え方の確認用）

## テスト

```
node test.mjs
```

実ファイルから読んで検査するので、ページを直すとテストも追随する。見張っているのは:

1. 端末判定（クローラ・Kindle Fire・iPadOS の偽装UA・platform が嘘をつく場合を含む）
2. **主ボタンの付け替えが、自動遷移より前にあること** — 後ろにあると、遷移が
   塞がれた環境で「間違ったストアが主役の画面」が残る
3. OGP の絶対URLが、いま配信しているドメイン（CNAME）を指していること —
   ドメインを移したときの取りこぼしを防ぐ
